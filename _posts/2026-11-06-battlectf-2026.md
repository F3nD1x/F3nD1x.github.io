Cette page regroupe mes write-ups de la **phase qualificative du battleCTF 2026** (plateforme bugpwn), où j'ai terminé **15ème sur 552** ([voir la distinction]({% post_url 2026-11-06-top-15-battlectf %})).

Les write-ups complets sont sur GitHub : [F3nD1x/BattleCTF-writeup](https://github.com/F3nD1x/BattleCTF-writeup). Les flags y sont caviardés.

## Web

- [SwiftNotes](https://github.com/F3nD1x/BattleCTF-writeup/blob/main/web/swiftnotes.md) : prototype pollution vers RCE EJS
- [WireVault](https://github.com/F3nD1x/BattleCTF-writeup/blob/main/web/wirevault.md) : timing d'auth, fuite de cache et race condition
- [TicketVault](https://github.com/F3nD1x/BattleCTF-writeup/blob/main/web/ticketvault.md) : injection de filtre NoSQL et broken access control (IDOR)
- [ClearHouse](https://github.com/F3nD1x/BattleCTF-writeup/blob/main/web/clearhouse.md) : IDOR GraphQL, path traversal et RCE js-yaml v3
- [EchoGate](https://github.com/F3nD1x/BattleCTF-writeup/blob/main/web/echogate.md) : HTTP request smuggling CL.TE vers l'accès admin interne
